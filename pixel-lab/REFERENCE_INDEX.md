# ASHUR Pixel Lab — Reference Index

This file is the source of truth for visual reference discovery. Read it before starting or revising pixel-art work. The gallery is at https://xopo6o.github.io/ASHUR/pixel-lab/references.html.

## Working rules

1. Before drawing, inspect the relevant references in the category folders below and the curated cards in `references.html`.
2. Keep original uploads unchanged. Never overwrite an existing reference to publish a revision; add a new file with a new version suffix.
3. An upload is a reference, not automatic approval. Do not label an image "approved", "final" or "master" unless the user explicitly approves it.
4. Treat explicitly marked candidates and studies as non-final. Compare against the user's chosen master reference before claiming similarity.
5. For a character task, inspect all relevant character references together (front/side/three-quarter views, proportions, face, clothing, accessories and silhouette). Do not invent missing design features as if they were established.
6. When a new image is uploaded, add its exact path, category, short description and status to this index in the same change where practical.
7. Keep ASHUR trading code and its server separate from this visual asset archive.

## Status vocabulary

- **Master / approved** — explicitly approved by the user.
- **Reference** — visual source to study; not necessarily a target to copy exactly.
- **Candidate** — proposed version awaiting review.
- **Study** — experiment; do not treat as production-ready.
- **Rejected** — retained for history only; do not use as a positive target.

Update this index as the archive grows. The index and original image files together are the persistent visual memory for ASHUR Pixel Lab.
