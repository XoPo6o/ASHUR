Управление референсами

Загрузка, переименование, перенос между категориями и удаление — прямо здесь. Файлы сохраняются в архиве ASHUR.

Подключение GitHub

Создай Fine-grained token: Repository access → Only select repositories → XoPo6o/ASHUR; Repository permissions → Contents → Read and write. Другие права не нужны. Токен хранится только в памяти страницы и не сохраняется браузером.
